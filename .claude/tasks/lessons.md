# Lessons

## 検証できないときは fail closed(2026-09-14)

- 削除など不可逆な操作の前提チェック(世代確認の inspect など)が失敗したとき、「失敗 = チェック通過」で先へ進めない。not found は「消すものがない = 成功」、それ以外のエラーは中止して返す。
- レビュー指摘の修正時は、修正した関数のエラー分岐を全部たどり、fail open な経路が残っていないか確認してから完了と言う。
- 「バックエンドの制約で閉じられない」と結論する前に、別の層(バックエンドが返す不変 ID の保持、同一ホストでの flock など)で閉じられないかを検討する。制約の説明はレビュー指摘への回答にならない。
